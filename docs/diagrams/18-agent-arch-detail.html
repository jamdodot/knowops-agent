Agent 分层与协作链路 · 细化视图

自上而下为请求流转方向；每个方框拆到子组件级并标注作用。组件名与 agent-service/、java-service/ 中的实际模块一致，出处见 docs/18-架构分层与协作链路-细化视图.md。

线型语义
同步调用（阻塞等待）
异步 / A2A 委派（不共享调用栈）
回流（事件、证据、降级标记向上）
图中不存在反向实线：Python 永不主动调 Java
1
接入层
接入层 只消费 SSE，不参与任何决策 不解析引用编号：正文带 eid 占位符，编号由前端按 citations[] 渲染
web 演示页index.html / app.js / styles.css
消费 SSE 流；按 citations[] 渲染引用骨架并跳转页码；展示 TOC 与 degraded[] 提示。
业务前端知识问答页 / 排障工单页
发起提问；展示诊断推进过程（progress / evidence）；承接审批与补充信息弹窗。
HTTP + SSE
2
网关层
业务网关 · java-service Spring Boot，49 个 Java 文件 权限的唯一计算点：Python 不查权限表，只接受已收敛属性
contract/（codegen DTO）契约
AnswerRequest / Task / 8 类事件 / SubjectContext
由 api/openapi.yaml 生成，两端都不手写 DTO，从根上杜绝字段漂移。
KnowledgeGatewayController
POST /v1/knowledge/answers
知识问答入口，返回 text/event-stream；透传已注入主体的 subject_ctx。
FulfillmentGatewayController
POST /tasks · GET /{id} · /resume · /cancel
排障诊断入口；维护 Task 生命周期、幂等 resume 与 TTL 清理。
acl/SubjectResolver安全
→ InMemorySubjectResolver
把部门树 / 角色 / 共享组 / 审批单收敛成 subject_ctx；account_status 一票否决。
gateway/AgentGateway契约
→ WebClientAgentGateway
转发、预算、重试、取消的唯一实现处：带 X-Deadline-Ms 剩余预算、Idempotency-Key；只在首帧前重试；断连即取消上游。
UploadController + LocalUploadService
/v1/upload
原件落盘、触发解析与入库（M0 本地实现，后续替换为对象存储直传）。
会话 / 配额 / 审批 / 审计
chat_turn · 待办 · 计数
落 chat_turn(status, usage, finish_reason)；动作审批待办；INJECTION_BLOCKED 单独计数，不混进 5xx 错误率。
REST + SSE（knowledge） / REST + SSE + Task（fulfillment）
↑ 回流：meta → citation → delta → done ｜ progress / evidence / input_required
3
域层
域层 · 唯一的业务语义所在地 两域共用同一镜像、同一 Runtime，差异全落在 domain.yaml 唯一横向边：A2A 双向，必须携带 scope.chain
knowledge :8001 无状态 · 一请求一条流
api/app_knowledge.py契约
建流前预检四步：契约版本 → 主体红线 → 注入检测 → 图白名单。回了 200 就没有 4xx 的机会。
Agentic RAG 图（9 节点）
analyze_intent → plan → retrieve → grade ⇄ rewrite → synthesize → verify → abstain
广度检索 + 早停；改写回环最多 2 轮；abstain 独立成节点，拒答是正常路径。
工具 hybrid_retrieve / doc_fetch只读
唯一数据入口；工具实现不接受 subject 参数，权限不经参数泄漏。
delegate（A2A 委派节点）
问句含订单号时把诊断外包给 fulfillment；当前仅 graph_pipeline 引用，agentic 主图未接。
api/sse.py · replay.py · schemas.py
帧编码 + 15s 心跳 + Channel 回压；幂等命中重放整条流（含 meta）；pydantic extra="forbid"。
A2A 委派
最小 scope
chain 防环
跳数 ≤ 2
fulfillment :8002 有状态 Task · resume / cancel
api/app_fulfillment.py契约
Task 状态机 submitted → working → (input_required) → completed/failed/canceled；resume 用 Command(resume=)，不是重发 inputs。
假设验证图（10 节点）
analyze_symptom → clarify ⟂ → hypotheses ⇄ gather/refine → evaluate → compose → propose → approve ⟂
深度取证 + 允许证伪；clarify / human_approve 两个 interrupt 让流关闭、连接不再被占用。
工具 9 个只读写=提议
订单 / 库存 / 物流 / 支付 / 日志 / 指标 / 规则 / 动作 / ask_knowledge
查询走 sqlguard 只读白名单；写操作只 propose_action，执行永远走 Java 审批。
checkpointer
PostgresSaver / InMemorySaver
checkpoint 落在 interrupt 之前，断流后仍能唤醒；断流 ≠ 失败。
Task 幂等与 TTL契约
409 DUPLICATE_INFLIGHT / TASK_STATE_CONFLICT
同一幂等键在跑 → 让其重连原流；状态不允许 resume → 409；过期 Task 走 TTL 清理。
节点只能走 GraphBuilder.node()
4
内核层
Runtime 内核 · runtime/ 约 3110 行；编排用 LangGraph，约束层自研 域无关：源码里出现域名，test_domain_isolation 直接失败
graph.py · GraphBuilder / run()闸门
StateGraph 门面 + 节点唯一包装：enter_node 计步与预算 → span → fn(state, rt)；GraphBubbleUp 原样上抛。不暴露 add_node。
events.py · Ledger预算
步数 / token / 成本 / 截止时间四限，任一超限在节点边界硬停，不是节点跑到一半。on_budget 决定 abstain 还是 escalate。
events.py · EventSink契约
SSE 唯一出口与状态机：citation 不得晚于 delta、eid 必须发出过、done/error 用 _terminal_once 保证唯一、close() 未终态直接抛。
registry.py · ToolRegistry治理
schema 校验 · 线程池超时（3s / 10s 分级）· copy_context · 超 1500 字符立即压缩。
guard.py · Guard安全
注入检测（入）· 输出脱敏（出，切点避开数字与 @）· 动作白名单（写的是动作类型，不是工具名）· risk_of() 分级。
memory.py
工作记忆（窗口）/ 语义（用户偏好，接口已留）/ 情景（成功工单，按域隔离）。M0 为词面打分，不是向量检索。
prompts.py · PromptLibrary
manifest 登记制（缺登记启动即失败）+ 模板/渲染双 sha，sha 进 meta.prompt_set_sha，trace 可回溯到具体版本文本。
llm.py · LLMProvider
直连 OpenAI 兼容协议、重试退避、尾帧 usage 回填账本；online 缺 key 时宁可起不来也不回落 mock。
config.py · DomainPack启动校验
domain.yaml 强类型加载 + 启动期三查：graph == 模块 NAME、tools 全注册、prompts 全可加载。
sqlguard.py只读
只读 SQL 白名单、语法与对象检查、强制 LIMIT、mask_rows 行级脱敏。
tracing.py
OTel 薄封装 + span_tree() 自检；节点漏埋 span 会导致 trace 断链、归因失效。
errors.py
KwError / BudgetStop / ContractViolation / DegradedEnum：降级只有一个入口，不允许各处静默吞。
registry.call() / 只读依赖
5
能力层
能力层 无状态，可被任一域复用；不含业务语义 权限在检索之前：permitted CTE 与排序同一条 SQL
parse/ 解析
pipeline · router · engines · ir · chunker
按页路由 L0 直取 / Docling / MinerU，统一 IR 后做语义分块与父子块（子块检索、父块喂模型）。
retrieval/ 检索ACL 下推
pg_retriever · embed · rerank · memory_retriever
dense(BGE-M3) + BM25 双路 → RRF 融合；rerank 可选，超时记 degraded 但流照常 done。
a2a/ 跨域协议唯一横向
client · server · types
Agent Card 发现 + JSON-RPC；出站追加本域到 chain，服务端在 handler 之前拒绝回环。
api/ 通用件
sse · replay · schemas
帧编码与回压、幂等重放、契约模型；被两个域入口共用，避免两份实现漂移。
读 / 写（Python 对业务库只读）
6
底座
底座 读写分离：读模型在 PG，业务真相在 MySQL Python 侧永不写业务库：写操作只提议，执行走 Java 审批
PostgreSQL 读模型
kb_chunk · kb_doc_mirror · checkpoint · memory
带 ACL 快照的检索单元；pg_search 中文分词索引；checkpoint 支撑 resume。
MySQL 业务真相只读
订单 · 库存 · 物流 · 支付
权限由静态共享 / 动态共享 / 审批单共同决定，判定在 Java 与知识域，排障域不直读文档库。
MinIO 原件
PDF / Word / Markdown 原始文件；引用可回溯到具体页，解析失败可重跑。
模型服务
models.yaml · 线上 API / mock
角色（analyze / generate / classify）→ provider/model 映射 + 计价表；调用成本入账本。
埋点（不阻塞主链路）
7
观测层
观测层 OTel → Langfuse / OTLP _debug/trace/{trace_id} 不依赖 collector，本地即可看 span 树
trace 归因
节点级 span + trace_id 贯穿 Java 与 Python；错误帧必须带 trace_id。
成本与预算观测
每轮 usage{tokens, cost_usd} 落账本并落库；成本异常先看角色映射与计价表。
安全与降级计数
INJECTION_BLOCKED 与 degraded[] 单独计数，不与 5xx 混算。

五条不变量（可直接当验收标准）

  • 1 权限在检索之前 — permitted CTE 与排序同一条 SQL
  • 2 引用先于正文 — sink.citation 检查 _delta_started
  • 3 终止事件唯一 — _terminal_once + close()
  • 4 预算在节点边界 — Ledger.enter_node()
  • 5 域隔离 — test_domain_isolation.py 扫源码

跨层约束的机器守卫

  • 契约里不存在文档清单 — pydantic extra="forbid"
  • 动作白名单写动作类型 — test_guard.py
  • 已交付不可反悔（abstained → degraded）— test_finish_reason.py
  • 启动期三查 — runtime/config.py，不符就起不来
  • online 缺 key 不回落 mock — llm.build_provider

三处要与"已实现"区分开

  • 语义记忆：配置开了，但没有 rt.recall("semantic") 消费者
  • 图谱扩展：graph_expand / Neo4j 第三路未实现，只有 dense + BM25 + RRF
  • A2A 委派：通道双向已通，但 knowledge → fulfillment 仅挂在 graph_pipeline
