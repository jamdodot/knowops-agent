# corpus-v2：业务制度语料

> 44 份制度文档 / 295 chunk / 4.3 万字，7 个业务域，18 份带 ACL。
> 用途：知识域检索与问答的评测底座。**不是**产品演示数据——它刻意造得「不好答」。
>
> 目录里只放数据。本文件放在 `docs/` 而不是 `deploy/corpus-v2/`，因为入库脚本按
> `*.md` 扫目录，放进去会被当成第 45 份制度灌进库。

## 1. 为什么要重造

第一版语料只有 4 份文档、21 个 chunk。那个规模下：
`top-5 就覆盖全部相关内容 → Recall 恒为 1.0 → 管线式端到端 100% → Agentic 的改写永远不触发`。
指标全部饱和，等于没测。

所以这一版的目标不是「文档更多」，而是**让单次检索真的可能不够用**。

## 2. 目录结构

```
corpus-v2/
├── <域>-<制度名>.md          44 份正文（Markdown，条文体）
└── <同名>.acl.yaml           18 份访问控制声明（没有的即全员可见）
```

命名前缀：`HR` 人事 / `FIN` 财务 / `PUR` 采购 / `WMS` 仓储 / `OMS` 订单履约 / `IT` 信息技术 / `CS` 客服。

## 3. ACL 四档（含一档反向）

| 声明 | 文档数 | 谁可见 |
|---|---|---|
| `depts: ["D10"]` | 12 | 总部各部门（含 D10.3 等子部门）；D20 分公司/外包不可见 |
| `depts: ["D10.9"]` | 2 | 仅薪酬部门（`FIN-社保与公积金`、`FIN-薪酬结构与调薪`） |
| `roles: ["payroll"]` | 1 | 仅薪酬岗角色，比 D10.9 更窄（`FIN-工资核算与发放`） |
| `depts: ["D20"]` | 3 | **仅分公司**：总部员工反而不可见 |

前三档是**向总部收窄**，且故意做成嵌套（D10.9 ⊂ D10，payroll ⊂ D10.9），
这样「越权拒绝」不能靠「文档在不在库里」蒙对，必须真的算 scope。

第四档方向相反，用来补一个致命盲区：只测「分公司看不到总部」会掩盖
「总部也看不到」的 bug。ACL 下推到 SQL 时如果把 `depts` 写成「附加可见」而不是
「限定可见」，前 15 份文档的越权题**全绿**，而这 3 份会立刻全红。
两个方向都有题，这个错误才拦得住。

`acl_epoch: 1` 是权限声明的版本号，用于下发变更后的缓存失效。

### 3.1 选载体的原则：隔离文档必须与「受限方」主题正交

第一版 D20 文档我选了《分公司属地社保与公积金缴纳细则》，结果和 D10.9 的
《社保与公积金缴纳实施细则》讲**同一件事**——两份都写「基数每年 7 月调整」。
于是 outsider 合法地从 D20 文档读到「7 月」答了出来，被 u-105 的禁用词判成泄漏。

这不是标注错，是**载体选错了**：如果两个主体本来就该知道同一个事实，就测不出隔离。
改成《分公司属地用工备案与残保金申报》——总部完全不办这件事（备案属地办、
残保金分公司独立缴纳），主题上与 D10 正交，冲突才消失。

**所以新增受限文档后必须做两步验收，缺一不可：**

1. **禁用词全域扫描**：每个禁用词的 `出现文档集合 ⊆ forbidden_doc_ids`。
   这次就抓出 2 处——u-110 的「一律不予批准」被新文档撞上、u-104 的「16%」
   在弹性工作与订单时效两份公开文档里也有（太泛，答对会被误判泄漏）。
2. **跑一遍越权集**，泄漏率必须仍为 0。只做第 1 步不够：
   词不冲突不代表检索不会把新文档带进来。

## 4. 三类刻意安排（评测能不能分辨好坏全靠它们）

**① 跨文档才能答完**
- 出差流程在 `HR-员工出差管理办法`，住宿金额在 `FIN-差旅费用标准细则`；
- 远程办公能不能碰机密数据，规则在 `HR-弹性工作与远程办公管理办法`，密级定义在 `IT-数据分级与访问控制规范`；
- 报废服务器前要谁清数据：`FIN-固定资产` 与 `WMS-呆滞与报废` 各写了一半。

**② 同义不同词**
- 问「超时没发货」，文档写「超时未发货 → `E-4001`」；
- 问「几天内把钱退回来」，文档写「1 个工作日内发起，原路退回」。

考的是召回，不是字符串匹配。BM25 用合取（`@@@`）在这种问句上直接 0 命中——这是本轮真踩到的坑，
改析取（`|||`）后 `Recall@50` 才回到 1.0。

**③ 相邻但不覆盖（拒答题的来源）**
每份制度都只写自己那一层。比如住宿标准写了金额，但没写「超标部分能不能特批」；
报销时限写了 30 天，但没写「跨年怎么算」。这类题正确答案就是**拒答**，
用来测「该拒不拒」。

## 5. 已知缺口

- ~~没有 D20 专属文档，只测了单向越权~~ → 已补 3 份 D20 专属文档 + 12 条反向题，
  control 指向 `outsider`，保证「拒答正确」不是因为检索坏了。
- 文档都是 Markdown 条文体，没有真实 PDF 的版式噪声（页眉、表格跨页、双栏）。
  解析链路的鲁棒性不在这一版语料的覆盖范围内。
- 没有多版本并存（同一制度的新旧两版）。真实知识库里「现行版 vs 已废止版」是高频难题，
  现在只靠单版本，测不出「引用了作废条款」这类错误。
